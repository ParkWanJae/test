

# 고양이가 좋아하거나 관심 가지는 동물

* **작은 동물**

  * ex) 쥐, 새, 물고기, 곤충 등
  * 사냥 본능을 자극함 (움직임이 빠르고 작을수록 더 좋아함)
* **같은 종(다른 고양이)**

  * 낯가림 심하지만 익숙해지면 친해짐
  * 단, 성격 차이 크면 싸움남
* **사람**

  * 신뢰 형성되면 좋아함
  * 특히 자신에게 밥 주거나 놀아주는 사람

# 고양이가 싫어하는 동물

| 종류    | 이유              |
| ----- | --------------- |
| 개🐕   | 소리 크고 갑작스러운 움직임 |
| 큰 새🦅 | 본능적으로 경계함       |
| 뱀🐍   | 생존 본능상 두려움      |

(검증 필요): 일부 고양이는 햄스터나 토끼처럼 작고 조용한 동물과도 잘 지내는 경우 있음.
